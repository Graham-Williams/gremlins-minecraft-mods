# Warden's Wings

A Minecraft datapack (and, later, a full Fabric mod) that lets you fuse an **Elytra**
onto a **Netherite Chestplate** — netherite-tier protection *and* flight in one piece —
but only after completing a brutal end-game **gauntlet** across every marquee structure
and boss in the game. It's meant to be genuinely hard to earn.

- **Target:** Minecraft **26.1**, Fabric server (datapack first; no client install required to play).
- **Roadmap:** the datapack is the playable prototype; a polished **Fabric mod** (real custom
  item, texture + wings, config) is the eventual Modrinth release.

## Status

🚧 **Design phase.** The gauntlet, naming, and difficulty are being finalized via a
questionnaire before any datapack code is written. Nothing is built yet.

Design questionnaire: see `DESIGN.md` for the working spec and the link to the
fill-out doc.

## The idea (subject to the questionnaire)

Two-stage forge:
1. Collect a rare trophy from each challenge (Warden, Trial Chamber, Woodland Mansion,
   Ocean Monument, the Wither, ancient debris, an End City ship…).
2. Craft the trophies into a **Warden's Core**, then smith **Netherite Chestplate + Elytra
   + Core** together into **Warden's Wings**.
